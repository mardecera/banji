Cada app comparte arquitectura de **features**, i18n por path y paquetes `@banji/*`. En producción viven en subdominios de `banji.dev`.

## banji-web

Hub que reúne y presenta el resto de herramientas. Producción: [banji.dev](https://banji.dev).

```bash
pnpm --filter banji-web dev   # :3000
```

## banji-go

Acortador de URLs. Producción: [go.banji.dev](https://go.banji.dev).

```bash
pnpm --filter banji-go dev   # :3001
```

## banji-crypt

Cifrado en el navegador. Producción: [crypt.banji.dev](https://crypt.banji.dev).

```bash
pnpm --filter banji-crypt dev   # :3002
```

## banji-docs

Sitio de documentación (Fumadocs). Producción: [docs.banji.dev](https://docs.banji.dev). En local: `http://localhost:3003`.

```bash
pnpm --filter banji-docs dev   # :3003
```

## Desarrollo local

Con una sola app, en otra terminal:

```bash
pnpm package:watch
```

Recompila paquetes al cambiar código en `packages/`.

## Deploy (Vercel)

Un proyecto por app:

- **Root Directory:** `apps/banji-web` (o `banji-go` / `banji-crypt` / `banji-docs`)
- **Install:** `pnpm install`
- **Build:** `cd ../.. && pnpm turbo build --filter=<app>`
- **Dominios:** `banji.dev`, `go.banji.dev`, `crypt.banji.dev`, `docs.banji.dev`
- **banji-docs:** `NEXT_PUBLIC_DOCS_URL=https://docs.banji.dev`
