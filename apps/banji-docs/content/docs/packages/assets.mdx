## Subpaths

| Import | Contenido |
| --- | --- |
| `@banji/assets/icons` | Iconos React (SVGR) |
| `@banji/assets/illustrations` | Ilustraciones |
| `@banji/assets/images/*` | Imágenes estáticas |
| `@banji/assets/fonts.css` | `@font-face` Ubuntu |

```tsx
import { Icon } from "@banji/assets/icons";
```

Las fuentes se incluyen en el tema global vía `@banji/ui/globals.css`.
